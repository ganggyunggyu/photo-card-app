## 기본 사용법

### 바코드 스캔하기

1. 키오스크 화면의 카메라 영역에 바코드가 보이도록 쿠폰을 들어주세요
2. 바코드가 인식되면 자동으로 검증이 시작됩니다
3. 유효한 바코드인 경우 포토카드가 자동으로 배출됩니다

> **Tip**: USB 바코드 리더기가 연결되어 있다면 리더기로 스캔해도 됩니다

## 관리자 모드

### 관리자 모드 활성화

**화면 좌측 상단**을 **1초 이내에 3번 터치**하면 관리자 모드가 활성화됩니다.

```
┌──────────────────────────────┐
│ ▓▓▓▓                         │  ← 이 영역 (좌상단 100x100px)
│ ▓▓▓▓                         │     3번 빠르게 터치
│                              │
│                              │
│      [카메라 영역]            │
│                              │
└──────────────────────────────┘
```

### 관리자 모드 비활성화

같은 방법으로 **좌측 상단 3번 터치**하면 관리자 모드가 비활성화됩니다.

### 관리자 모드에서 표시되는 정보

관리자 모드가 활성화되면 **우측 상단**에 배출기 연결 상태 버튼이 표시됩니다:

| 상태 | 버튼 색상 | 텍스트 |
|------|----------|--------|
| 연결됨 | 🟢 초록색 | "배출기 연결됨" |
| 연결 중 | 🔵 파란색 (깜빡임) | "배출기 연결중..." |
| 연결 끊김 | 🔴 빨간색 | "배출기 연결 끊김" |

## 배출기 페어링

### 페어링 방법

1. **관리자 모드 활성화** (좌상단 3번 터치)
2. 우측 상단의 **"배출기 연결 끊김"** 버튼 터치
3. 블루투스 페어링 팝업에서 **"PhotoCard"** 장치 선택
4. 연결 완료 시 버튼이 **"배출기 연결됨"**(초록색)으로 변경

```
┌──────────────────────────────┐
│                    [연결 버튼]│  ← 이 버튼 터치
│                              │
│                              │
│      [카메라 영역]            │
│                              │
└──────────────────────────────┘

        ↓ 터치 후

┌─────────────────────────────────┐
│   블루투스 페어링               │
│   ──────────────────────────    │
│   🔷 PhotoCard          [연결]  │  ← 이 장치 선택
│                                 │
└─────────────────────────────────┘
```

### 페어링 해제

우측 상단의 **"배출기 연결됨"** 버튼을 터치하면 연결이 해제됩니다.

### 자동 재연결

연결이 끊어지면 최대 **3회** 자동 재연결을 시도합니다.

## 피드백 화면 안내

바코드 스캔 후 결과에 따라 다른 피드백 화면이 표시됩니다.

### 성공 (포토카드 발급 완료)

```
┌──────────────────────────────┐
│                              │
│     ✅ (성공 애니메이션)      │
│                              │
│    "포토카드 발급 완료!"      │
│                              │
│        (5초 후 닫힘)         │
└──────────────────────────────┘
```
- **배경색**: 초록색
- **표시 시간**: 5초
- **의미**: 바코드 확인 완료 + 포토카드 배출 성공

### 이미 사용된 바코드

```
┌──────────────────────────────┐
│                              │
│     ⚠️ (경고 애니메이션)      │
│                              │
│      "이미 사용된 쿠폰"       │
│                              │
│        (3초 후 닫힘)         │
└──────────────────────────────┘
```
- **배경색**: 노란색/주황색
- **표시 시간**: 3초
- **의미**: 해당 쿠폰은 이미 사용되었음

### 유효하지 않은 바코드

```
┌──────────────────────────────┐
│                              │
│     ❌ (에러 애니메이션)      │
│                              │
│    "유효하지 않은 바코드"     │
│                              │
│        (3초 후 닫힘)         │
└──────────────────────────────┘
```
- **배경색**: 빨간색
- **표시 시간**: 3초
- **의미**: 등록되지 않은 바코드

### 배출 실패

```
┌──────────────────────────────┐
│                              │
│     ❌ (에러 애니메이션)      │
│                              │
│      "배출에 실패했어요"      │
│     직원에게 문의해주세요     │
│                              │
│        (3초 후 닫힘)         │
└──────────────────────────────┘
```
- **배경색**: 빨간색
- **표시 시간**: 3초
- **의미**: 바코드는 유효하지만 배출기 오류 발생

## 문제 해결

### 배출기가 연결되지 않아요

1. ESP32 배출기의 전원이 켜져 있는지 확인
2. 관리자 모드에서 수동으로 연결 시도
3. 블루투스가 활성화되어 있는지 확인 (Chrome 브라우저 필요)

### 바코드가 인식되지 않아요

1. 바코드가 카메라 영역 안에 완전히 들어오는지 확인
2. 바코드가 구겨지거나 손상되지 않았는지 확인
3. 조명이 충분한지 확인 (너무 어둡거나 반사가 심하면 인식 어려움)

### 화면이 응답하지 않아요

1. **2초 대기** - 피드백 표시 후 쿨다운 시간이 있음
2. 브라우저 새로고침 시도
3. 키오스크 재시작

### "카메라 권한이 필요합니다" 오류

브라우저 설정에서 카메라 권한을 허용해주세요:
- Chrome: 주소창 좌측 자물쇠 아이콘 → 카메라 → 허용

## 시간 설정

| 상황 | 시간 |
|------|------|
| 성공 피드백 표시 | 5초 |
| 실패/경고 피드백 표시 | 3초 |
| 피드백 후 재스캔 대기 | 2초 |
| 관리자 모드 활성화 터치 간격 | 1초 이내 |

## 요약 (Quick Reference)

| 기능 | 방법 |
|------|------|
| 관리자 모드 ON/OFF | 좌상단 3번 터치 (1초 이내) |

| 배출기 연결 해제 | 관리자 모드 → 우상단 "연결됨" 버튼 터치 |
